# Avora Personal Finance
Gestor e guia de finanças pessoais 

## o que resolver ? 
Organiza e guia sobre finanças pessoais de pessoas fisicas no Brasil de forma a melhorar a gestão de médico, curto e longo prazo. 


## Requisitos Funcionais (RF): 
* RF1 Login e Senha  
* RF2 Controle de Categorias 
* RF3 Controle de Lançamentos de entradas 
* RF4 Controle de Lançamentos  de saída  
* RF5 Controle de versão 
* RF6 Dados de integrados com o OpenFinance 

## Requisitos Nāo Funcionais (RNF):
* RNF1 Controle dados com backup 
* RNF2 
* RNF3 
* RNF4
