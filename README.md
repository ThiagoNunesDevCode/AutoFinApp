# AUTOFIN APP 
Gerencimento de Finanças Automático 

## o que resolver ? 
Facilita o processo de categorização de gastos e organização de finanças. 

##  Como resolve? 
Através de aplicação WEB conectado com uma API do OpenFinance pessoal o qual informa todas as transações de contas de banco de de cartões de crédito conforme lista de instituições cobertas. 



## Requisitos Funcionais (RF): 
* RF1 Login e Senha  
* RF2 Controle de Categorias 
* RF3 Controle de Lançamentos de entradas 
* RF4 Controle de Lançamentos  de saída  
* RF5 Controle de versão 
* RF6 Dados de integrados com __Api OpenFinance__ 
* RF7 Controle de Contas em Banco
* RF8 Controle de movimentação dentro da mesma conta 

## Requisitos Nāo Funcionais (RNF):
* RNF1 Controle dados com backup 
* RNF2 DashBoarde
* RNF3 Intergace Visual em WEB 
* RNF4 Noticação quando haver movimnetações pendentes para que sejam atualizadas na aplicação.
